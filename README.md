# Salary Prediction Using Machine Learning

This project predicts estimated salaries based on gender, education level, job title, and years of experience.

## Technologies Used
Python, Pandas, NumPy, Scikit-learn, Pickle, and Gradio.

## Models Used
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- K-Nearest Neighbors (KNN)

## Features
- Data preprocessing and categorical encoding
- Model training and comparison
- Evaluation using MAE, RMSE, and R² score
- Interactive salary prediction using Gradio
